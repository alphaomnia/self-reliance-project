# self-reliance-project

This is the self reliance and survival project that is a standalone version that lives on your phone for survival.

## Install on a phone

Open https://alphaomnia.github.io/self-reliance-project/ then:

- **iPhone or iPad:** open it in Safari, tap Share, then Add to Home Screen.
- **Android:** tap Install app, or Chrome menu then Install app.

It works with no internet once installed. Open it once a month while online to receive updates.

## Files

| File | Purpose |
|---|---|
| index.html | The whole guide, also usable as a single offline file |
| sw.js | Keeps the guide available offline |
| manifest.webmanifest, icons | Home screen app |
| version.json | Lets installed copies know a newer version exists |
